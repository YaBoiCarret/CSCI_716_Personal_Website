# Garret Doty — Live Portfolio

This repository contains the source code for my personal portfolio site, hosted on **GitHub Pages** at:  
 [https://github.com/YaBoiCarret/CSCI_716_Personal_Website]

## Project Overview
The purpose of this project is to create a live portfolio that I can expand over time with new content and features.  
This site will include:
- **Home Page** — introduction and navigation
- **About Section** — background and experiences
- **Projects Section** — showcase of projects
- **Contact Section** — simple way to connect

## Technology Stack
- **HTML / CSS** (basic layout and styling)  
- **GitHub Pages** (hosting)  


## Project Management
- Issues are used to track tasks and updates.  
- Labels (e.g., `documentation`, `enhancement`) classify the type of work.  
- A Project board (Kanban) organizes tasks into **To Do, In Progress, Done**.  
- Milestones (like *Sprint 1*) track progress across multiple issues.
